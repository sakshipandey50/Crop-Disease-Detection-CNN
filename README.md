# Crop Disease Detection Using CNN

## Overview
This repository contains the research paper:

**Crop Disease Detection Using Convolutional Neural Network (CNN)**

The study focuses on automated crop disease detection using deep learning techniques and image-based classification.

## Key Highlights

* CNN-based disease classification
* Dataset containing 54,000+ crop leaf images
* 97.8% training accuracy
* 95.4% validation accuracy
* Accepted for COSMIA 2026 Conference
